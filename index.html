Анализ продаж по акции. Excel обрабатывается локально в браузере.
Эти позиции не считаются получившими −30% именно по акции только из-за размера скидки.
Правила расчёта
Чек определяется по магазину и точному времени продажи. Эффективность акции рассчитывается по колонке «Описание скидки» в строках реализации: после исключения артикулов, у которых уже действует собственная скидка −30%, позиции с описанием «На вторую единицу 30%» считаются реализацией по акции. Артикулы с собственной скидкой −30% не учитываются как результат акции. Продажа сертификатов, услуги ушива/подшива и пакеты не учитываются ни в количестве чеков, ни в количестве единиц. Расчёт ведётся без привязки к сезонным группам, поэтому его можно использовать для разных брендов.
