Правила расчёта
Чек определяется по магазину и точному времени продажи. Эффективность акции рассчитывается по колонке «Описание скидки» в строках реализации: после исключения артикулов, у которых уже действует собственная скидка −30%, позиции с описанием «На вторую единицу 30%» считаются реализацией по акции. Артикулы с собственной скидкой −30% не учитываются как результат акции. Расчёт ведётся по чекам, без привязки к сезонным группам, поэтому его можно использовать для разных брендов.
